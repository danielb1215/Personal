# AI Context — Daniel Bolivar's Personal Repo

This repository is Daniel Bolivar's personal AI-assisted life management and entrepreneurship workspace.

## Purpose

Use this repo to:
1. Maintain a rich, structured context about Daniel's life, skills, and goals
2. Research and validate parallel income / side business opportunities
3. Plan and track experiments toward financial independence

## How to Use This Repo with AI

When starting a new session, the AI should read:
1. `persona/profile.md` — who Daniel is professionally
2. `persona/skills.md` — what he can do technically
3. `persona/hobbies.md` — how he lives and what he enjoys
4. `persona/finances.md` — financial baseline and constraints
5. `entrepreneurship/README.md` — current business exploration status

## Spec-Kit Integration

This repo has spec-kit installed. Use these skills to drive structured thinking:

| Skill | When to Use |
|-------|-------------|
| `/speckit-specify` | Define requirements for a business idea |
| `/speckit-plan` | Create an execution plan for a validated idea |
| `/speckit-tasks` | Break a plan into actionable steps |
| `/speckit-implement` | Execute tasks |
| `/speckit-analyze` | Cross-check consistency in specs and plans |
| `/speckit-clarify` | Resolve ambiguity before planning |
